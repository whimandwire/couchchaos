How to Play

Couch Chaos is a couch-friendly party game. Each turn, pick a mode or roll one, then follow the prompts. The app rolls genres, tones, timers, and jump methods so you can focus on laughing.

  1. Set player names and options in Settings.
  2. Hit Start Turn, choose Mode-First or Content-First.
  3. Roll a mode (or pick one), then roll the required prompts.
  4. Use the checklist and trackers to run the turn.
  5. Tap End Turn to log the summary and swap players.

Tip: enable seeded randomness to replay the same chaotic night.
